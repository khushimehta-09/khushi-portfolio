SecureAuth: Django Distributor Management Portal

A foundational Django web application featuring dual-role user models, a distributor onboarding approval workflow, authentication, login activity tracking, and support ticketing.

Context & Learning:

I developed this project during my 15-day Python with Django internship at BrainyBeam Info-Tech Pvt. Ltd., Ahmedabad (15 May 2026 – 29 May 2026). It demonstrates my practical, foundational Django knowledge. I used AI tools to assist with development and accelerate my learning of Django models and views.

Implemented Features:

  • Role-Based User Architecture: Custom Django user model with distinct Admin and Distributor roles.
  • Distributor Approval Workflow: Automatic Pending status upon distributor signup; Admin can approve, reject, or block accounts.
  • Email OTP Password Reset: 6-digit OTP generation with 5-minute expiration time.
  • Failed Login Tracking: Security lockout mechanism after consecutive failed login attempts.
  • Activity Audit Logging: Capture of IP addresses and browser user-agent on logins.
  • Support Ticket Desk: Internal ticketing module for distributor inquiries with admin response tracking.

Active Project

Smart Hospital Management System

A real-world medical and hospital software concept currently being planned and built to make hospital access and patient management smarter and more inclusive.

Core Architectural Concept:

I am actively developing this project with a focus on real-world accessibility. The system is designed with two distinct access workflows:

  • Staff-Assisted Access: Dedicated desks and flows for patients who cannot or do not want to use a smartphone or digital self-service.
  • Patient Self-Service: Intuitive flows for patients who are comfortable using their own digital devices for check-in and updates.
  • Emergency Patient Priority: Urgent cases are explicitly accounted for in the workflow so critical care is never hindered or delayed by normal registration or queue procedures.

Project Status Note:

This project is currently in the planning and development phase. It is not yet completed, clinically deployed, or connected to real medical records. Development is actively ongoing.
